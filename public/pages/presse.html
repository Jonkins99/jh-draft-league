Firestore blockiert die Presse

Die Collections der Presse sind in den Sicherheitsregeln nicht freigegeben. In der Firebase-Konsole ergänzen:

match /press/{doc} { allow read, write: if true; }
match /pressSessions/{doc} { allow read, write: if true; }
match /settings/{doc} { allow read, write: if true; }
